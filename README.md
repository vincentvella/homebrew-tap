# vincentvella/tap

Homebrew formulas for [velmux](https://github.com/vincentvella/velmux).

```sh
brew install vincentvella/tap/velmux
```

Prebuilt binaries for macOS (Apple Silicon, Intel) and Linux (x86_64, arm64).
The formula follows velmux's GitHub releases: a workflow checks hourly and
regenerates it (`bin/velmux-formula <tag>`) when there's a new one.
